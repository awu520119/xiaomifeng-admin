## 订单管理—订单详情

1. **主题信息**：在订单详情的「主题信息」中展示「起飞任务 ID」。
    - 单个起飞任务 ID 直接展示
    - ≥2 个起飞任务 ID，则默认折叠，可点击展开全部

2. **查看起飞任务**：
    - 点击起飞任务 ID：支持打开对应起飞任务详情抽屉。
    - 支持关闭起飞任务详情抽屉，恢复当前订单详情。
