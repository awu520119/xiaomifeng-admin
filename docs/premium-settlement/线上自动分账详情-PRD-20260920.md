## 线上自动分账详情

### 一、汇总说明

1. **页面头部**：面包屑依次展示「返回」、页面标题「线上自动分账详情」、结算对象「{账号}（{名称}）」。
2. **账期信息**：展示周期类型、账期、账单状态、统计范围。
    - **周期类型**：标签展示「周结」或「月结」。
    - **账期**：月结展示为「YYYY年MM月」，周结展示为「YYYY-MM-DD～YYYY-MM-DD」。
    - **账单状态**：标签展示，取值「审核中」「打款中」「已打款」「已驳回」。
    - **统计范围**：展示「{账期开始时间} — {账期结束时间}」，精确到日，时间部分补 00:00。
3. **范围筛选**：下拉单选，选项为「全部景区」加该账单涉及的景区列表，默认「全部景区」。
    - **数据来源**：账单关联订单所属景区的去重集合。
    - **刷新时机**：切换选项后，汇总指标与明细列表按所选景区同步刷新，不重新加载账单。
    - **取不到时**：账单无景区信息时，选项仅有「全部景区」，明细按全量展示。
4. **汇总指标**：按从左到右的顺序展示，指标之间以分隔线断开。下表口径中的「订单」，均指当前账单、当前景区范围内纳入结算的订单。

    | 汇总项 | 统计口径 | 展示条件 |
    | --- | --- | --- |
    | 订单笔数 | 订单数量，单位「笔」 | 始终展示 |
    | 订单金额合计 | 订单的支付金额之和；支付金额为空时取订单金额 | 始终展示 |
    | 退款金额合计 | 订单的退款成功金额之和 | 始终展示 |
    | 基础分成金额 | 应结算金额 − 溢价 | 结算对象为「景区商家」 |
    | 溢价 | 订单的分账快照中该结算对象的溢价金额之和 | 结算对象为「景区商家」 |
    | 应结算金额 | 订单的分账快照中该结算对象的应结算金额之和 | 始终展示 |
    | 已分账净额 | 分账状态为「已分账」的订单的分账金额合计，减去回退状态为「已回退」的订单的回退金额合计；结果小于 0 时展示 0 | 始终展示 |

5. **金额口径**：所有金额保留 2 位小数、千分位分隔、前缀「￥」；先按订单取值再求和，汇总结果四舍五入至 2 位小数。

### 二、明细列表

1. **展示范围**：当前账单、当前景区范围内的订单明细，字段顺序固定，不支持自定义列。
2. **列说明**（按从左到右的顺序）：

    | 列名 | 口径 |
    | --- | --- |
    | 订单号 | 展示订单号，可点击 |
    | 订单信息 | 展示订单主题；主题过长时截断，悬停展示完整内容 |
    | 拍摄点 | 展示订单所属拍摄点 |
    | 订单状态 | 标签展示，取值与颜色沿用订单状态既有定义 |
    | 下单时间 | 订单创建时间 |
    | 完成时间 | 订单完成时间 |
    | 订单金额 | 该订单的支付金额，右对齐；支付金额为空时取订单金额 |
    | 结算规则 | 该订单在该结算对象下的分账比例，展示「按比例 · {比例}%」，补充规则见「二、3」 |
    | 已分账净额 | 已分账金额 − 回退金额，结果小于 0 时展示 0，右对齐 |
    | 分账状态 | 标签展示，取值与展示规则见「二、4」 |
    | 应结算金额 | 该订单在该结算对象下的应结算金额，右对齐，加粗 |

3. **结算规则列**
    - **比例取值**：取该订单在该结算对象下已配置的分成比例；未配置或取不到时展示「按比例 · 0%」。
    - **景区商家附加**：结算对象类型为「景区商家」时，该单元格下方追加展示「基础 ￥{应结算金额 − 溢价} + 溢价 ￥{溢价}」。
4. **分账状态列**：取值「待分账」「待回退」「分账失败」「回退失败」「已分账」「已回退」「已冲减」「已生成分成」。
    - **取值优先级**：优先取回退状态，无回退状态时取分账状态，两者均为空时展示「待分账」。
    - **失败提示**：状态为「分账失败」或「回退失败」时，标签下方展示「原因：{失败原因}」；失败原因为空时展示「未返回失败原因」。
    - **重试入口**：状态为「分账失败」或「回退失败」且当前为自营后台视角时，标签下方展示「重试分账」/「重试回退」链接，文案随状态变化；非自营后台视角不展示该链接。
    - **无记录**：该订单在该结算对象下无分账记录时，整个单元格展示「-」。
5. **行内交互 —— 点击订单号**：跳转该订单的订单详情。订单详情属「订单管理」模块，本期不在本文档范围内。
6. **行内交互 —— 点击「重试分账」/「重试回退」**
    - **二次确认**：弹确认框，标题为「确认重试分账？」或「确认重试回退？」，内容依次展示订单号、分账金额或回退金额、收款方「{账号}（{名称}）」、失败原因；按钮为「确认重试」「取消」。
    - **确认后**：重试分账时先提示「订单 {订单号} 已提交重试分账」，分账完成后提示「订单 {订单号} 分账成功」；重试回退时提示「订单 {订单号} 回退成功，退款已完成」。

### 三、页面操作

1. **返回**：点击面包屑「返回」跳转来源页。
    - 由结算审批进入时返回「结算审批」。
    - 其他来源返回「结算中心」。

### 四、其他说明

- **范围**：本期仅覆盖「线上自动分账详情」视图；「线下对公结算详情」「推广方结算详情」沿用同一页面骨架，差异不在本文档范围内。
- **数据来源**：账单及其关联的订单与分账快照；进入页面时按账单 ID 加载，不做定时刷新。
- **账单不存在时**：展示「未找到该账单」并提供返回入口。
- **明细空态**：当前账单在当前景区范围内无订单时，明细列表展示「暂无订单明细」。
- **明细分页**：默认每页 10 条，不支持切换每页条数，右下角展示「共 {N} 条」。
