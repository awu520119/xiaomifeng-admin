# 结算审批-账期 PRD

*让财务在结算审批按三类结算对象查看已出账的账期，并下钻到账期明细核对账期应结算金额与订单是否一致。*

## 页签

| 控件 | 默认值 |
| --- | --- |
| 页签 | 景区商家结算 |

**页签**

- **取值**：景区商家结算 / 渠道结算 / 推广方结算。
- **记忆**：页签在会话内记忆最后一次选择，从账期明细返回后恢复到进入前的页签。
- **归属唯一**：账期按其结算对象类型归属唯一页签，同一账期不会出现在多个页签。
- **范围**：只处理线下对公结算账期，线上自动分账账期不进入本模块任何页签，也不出现在列表与明细中。

**结算对象**

- **停用后**：结算对象在后台停用后，其历史账期仍可查询、可查看明细，身份标识沿用停用前的账号与姓名。

【待确认·阻塞】账期出账后若所属结算对象被停用，账期是否继续进入审批流程。

- **权限与准入**：仅自营管理员、财务角色、其他自定义有「结算审批」权限角色可访问。其他角色整页报错「暂无结算审批权限，请联系系统管理员」，不加载列表数据。
- **导航与入口**：列表与账期明细同属「结算审批」，明细使用二级路由，页面标题与返回入口均归属结算审批，不跳转结算中心导航。

## 查询筛选项

| 筛选项 | 组件 | 占位符 | 默认值 |
| --- | --- | --- | --- |
| 周期 | 下拉 | 周期 | 空 |
| 账期 | 周 / 月选择器 | 账期 | 空 |
| 账单月份 | 月份 DatePicker | 账单月份 | 空 |
| 结算对象 | 可搜索下拉 | 查询账号、姓名 | 空 |
| 账单状态 | 下拉 | 账单状态 | 空 |
| 重置 | 链接按钮 | — | — |

**周期**

- **取值**：周结 / 月结。
- **可见性**：仅景区商家结算、渠道结算页签。

**账期**

- **可见性**：仅景区商家结算、渠道结算页签。
- **禁用**：未选周期时禁用并提示「先选择周期」，不允许单独选择账期。
- **联动**：周期被变更或清空时，已选账期一并清空，避免出现「周期周结、账期按月选」的组合。
- **匹配**：选周结并选定某一日期时，按该日期所在自然周的周一与账期起始日匹配；选月结并选定某一月份时，按所选月份与账期所属自然月匹配。

**账单月份**

- **可见性**：仅推广方结算页签。
- **匹配**：按月份匹配。

**结算对象**

- **候选范围**：当前页签已有账期的结算对象。

**账单状态**

- **取值**：审核中、打款中、已打款、已驳回；可清空。

**重置**

- **行为**：清空当前页签全部筛选项，含账单月份。

- **占位符**：筛选控件占位符直接用字段名，不加「全部」前缀；查询类输入框统一为「查询 xxx、xxx」格式。
- **生效方式**：各筛选项之间为「且」关系。
- **筛选项可见性**：推广方结算页签不展示周期与账期筛选项。

## 列表字段

| 列 | 内容 |
| --- | --- |
| 申请结算账期 | 账期主文案 |
| 周期类型 | 周结 / 月结 |
| 结算对象 | 账号（姓名） |
| 应结算金额 | 金额 |
| 账单状态 | 当前账单状态 |
| 收款账户信息 | 开户名、开户行、银行账号 |
| 备注 | 驳回相关提示 |
| 发票 | 下载入口 |
| 操作 | 查看明细 / 审核通过 / 审核驳回 / 线下打款 |

**申请结算账期**

- **悬浮**：悬浮展示完整起止时间。
- 账期只有周结与月结两种，起止时间与订单归属判断统一以 UTC+8 为准。
- 周结为自然周，区间为周一 00:00:00 至下周一 00:00:00（左闭右开），名称展示为 `YYYY-MM-DD～YYYY-MM-DD`，结束日为周日。
- 月结为自然月，区间为当月 1 日 00:00:00 至次月 1 日 00:00:00（左闭右开），名称展示为 `YYYY年MM月`。
- 订单按支付时间归属账期，落在 `[账期开始, 账期结束)` 内的订单计入该账期；未支付成功（实付金额不大于 0）与已取消的订单不计入任何账期。
- 周结在自然周结束后自动出账，时点为次周一 00:00:00；月结在次月 20 日生成上月账单。
- 同一结算对象在一个周期内只生成一个账期；一个账期只归属一个结算对象。
- 账期在出账时点由统计中转为已出账并进入列表，出账后不再新增订单。
- 账期内无符合归属口径的订单时不生成该账期。

【待确认·阻塞】账期出账后发生退款，退款金额是冲减原账期，还是计入退款发生时间所在账期。

**周期类型**

- **展示**：周结蓝色、月结灰色。
- 推广方固定使用月结，不提供结算周期配置，账期口径与月结一致。

【待确认·阻塞】结算对象变更结算周期（如周结改月结）的生效时点，以及在途账期的处理方式。

**结算对象**

- **展示**：账号为主文本，姓名为辅助文本。

**应结算金额**

- **展示**：￥ + 千分位两位小数。

**账单状态**

- **取值**：审核中、打款中、已打款、已驳回。
- **入列范围**：列表仅展示已出账且账单状态为上述四类的账期，其他状态不进入任何页签。

**收款账户信息**

- **展示**：银行账号脱敏展示。

【待确认·阻塞】收款账户信息是否取结算对象配置的银行账户，以及银行账号的脱敏规则。

**备注**

- **空值**：无备注时展示「-」。

- **现有系统能力**：账单状态与发票为现有系统能力，本 PRD 不定义。

**分页与空态**

- 无符合范围的账期时展示空列表「暂无待审批账期」。
- 分页默认每页 6 条，展示总条数。

【待确认】账期在列表中的默认排序规则。

## 列表操作

| 操作 | 位置 | 可用条件 |
| --- | --- | --- |
| 查看明细 | 行尾 | 所有行 |
| 审核通过 | 行尾 | 按账单状态 |
| 审核驳回 | 行尾 | 按账单状态 |
| 线下打款 | 行尾 | 按账单状态 |

**查看明细**

- **行为**：进入账期明细。

**审核通过 / 审核驳回 / 线下打款**

- **二次确认**：点击后弹出二次确认。

**审核与打款的可用条件**

【待确认·阻塞】审核与打款是否纳入本次需求范围——本次原型已实现三种操作的二次确认与状态流转，原文按「现有系统能力、不在本次范围」处理。

**审核驳回**

【待确认·阻塞】审核驳回时是否必填驳回原因；驳回原因是否展示在列表「备注」列。

**权限与入口**

【待确认·阻塞】自营管理员与财务在审核通过、审核驳回、线下打款三种操作上的权限是否一致。

## 异常和边界

**页签**

- 切换页签时清空该页签下已选的筛选项及账单月份值。
- 从账期明细返回时恢复进入前的页签，已选筛选项不保留。
