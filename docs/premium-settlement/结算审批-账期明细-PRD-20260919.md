# 结算审批-账期明细 PRD

*让财务在结算审批下钻到订单级明细，核对账期应结算金额与订单是否一致。*

## 页头与摘要

| 区域 | 展示内容 |
| --- | --- |
| 返回 | 返回入口 |
| 页面标题 | 线下对公结算详情 / 推广方结算详情 |
| 结算对象 / 周期类型 / 账期 / 账单状态 | 与列表一致的取数口径 |
| 统计范围 | 标签「统计范围」+ `{账期开始} — {账期结束}` |
| 范围筛选 | 景区下拉，占位「景区」 |
| 指标 | 订单笔数、订单金额合计、退款金额合计、应结算金额 |

**返回**

- **行为**：回列表并恢复到进入前的页签。

**页面标题**

- **取值**：按账期所属页签确定。

**结算对象 / 周期类型 / 账期 / 账单状态**

- **账单状态范围**：仅展示已出账且账单状态为审核中、打款中、已打款、已驳回的账期，其他状态不进入本页。

**统计范围**

- **展示**：展示完整起止时间。

**范围筛选**

- **取值**：「全部景区」+ 本账期涉及景区，默认全部。
- **联动**：切换景区范围后，指标区与明细表同步按所选景区重新统计，只影响展示、不改变账期数据。

**指标**

- 应结算金额 = 基础分成金额 + 溢价金额；溢价仅在景区商家账期展示。
- 该景区在本账期内无订单时，指标区按 0 统计。

## 明细字段

| 列 / 字段 | 展示内容 |
| --- | --- |
| 订单号 | 订单编号 |
| 订单信息 | 订单主题 |
| 拍摄点 | 订单拍摄点 |
| 订单状态 | 当前订单状态 |
| 下单时间 | 订单创建时间 |
| 完成时间 | 订单完成时间 |
| 订单金额 | 金额 |
| 结算规则 | 该订单的计算规则文本 |
| 应结算金额 | 该订单计入本账期的金额 |

**完成时间**

- **空值**：未完成展示「-」。

**订单金额**

- **展示**：￥ + 千分位两位小数。

**结算规则**

- **内容**：每笔订单展示其计算规则文本，用于判断该订单计入本账期的金额来源。

**应结算金额**

- **列名**：推广方账期的列名为「应分成金额」。
- **合计口径**：在「全部景区」范围下，明细的应结算金额合计等于该账期在列表中的应结算金额。

**归属口径**

订单按支付时间归属账期，落在 `[账期开始, 账期结束)` 内的订单计入该账期；未支付成功（实付金额不大于 0）与已取消的订单不计入任何账期。

**分页与空态**

- 分页默认每页 10 条，展示总条数。
- 账期无符合归属口径的订单时，明细展示「暂无订单明细」。

【待确认】账期明细中订单列表的默认排序规则。

## 操作

无。

## 异常和边界

- **账期无效**：账期已被移除或标识无效时不展示摘要与明细，统一展示「未找到该账单」并提供返回入口。
- **页面只读**：明细为只读页面，不提供对账期金额或订单的任何修改。
