# 结算中心-账期列表 PRD

*让结算对象在一个入口按三类结算方式查看自己的账期，并下钻到账期详情核对每一笔订单的分成与分账结果。*

## 页签

| 控件 | 默认值 |
| --- | --- |
| 页签 | 线上自动分账 |
| 视角 | 自营后台视角 |

**页签**

- **取值**：线下对公结算 / 线上自动分账 / 推广方结算。
- **记忆**：页签在会话内记忆最后一次选择：进入账期详情后返回、或会话内重新进入结算中心时，恢复进入前的页签。
- **归属**：线下对公结算页签仅展示景区商家与渠道账期，不含推广方账期；推广方账期统一在推广方结算页签展示，推广方固定月结。
- **周期**：线下对公结算与线上自动分账均同时包含周结与月结账期，同一结算对象按其自身配置的周期生成账期。

【待确认·阻塞】线下对公结算页签不再包含推广方后，历史已生成的推广方线下结算账期在哪个页签展示。

**视角**

- **取值**：自营后台 / 景区商家 / 渠道 / 推广方。
- **记忆**：三个页签均支持切换视角，视角不写入会话记忆。
- **数据范围**：自营后台视角可查看全部结算对象的账期与明细；其余三种视角仅展示本人数据，不展示其他结算对象的任何数据。
- **列可见性**：列可见性随视角变化，本节及下文以自营后台视角为基准描述全部列；其余视角仅收敛可见列与数据范围，不改变列的含义与计算口径。

## 查询筛选项

| 筛选项 | 组件 | 占位符 | 默认值 |
| --- | --- | --- | --- |
| 周期 | Select，可清空 | 周期 | 空 |
| 账期 | DatePicker，可清空 | 账期 | 空 |
| 对象类型 | Select，可清空 | 对象类型 | 空 |
| 结算对象 | Select，可清空、可搜索 | 查询账号、姓名 | 空 |
| 状态 | Select，可清空 | 状态 | 空 |
| 推广方手机号 | Input，可清空 | 查询推广方手机号 | 空 |
| 月份 | DatePicker（月份），可清空 | 月份 | 空 |
| 重置 | Link 按钮（蓝色链接） | — | — |

**周期**

- **取值**：周结 / 月结；清空表示全部周期。

**账期**

- **禁用**：未选周期时禁用，选择粒度随周期。
- **联动**：切换周期时清空已选账期。
- **匹配**：选择器用中文展示：月结按所选月份归属的自然月匹配，周结按所选日期归属的自然周的周一匹配。

**对象类型**

- **取值**：景区商家 / 渠道 / 推广方；仅自营后台视角。
- **联动**：已选对象类型时，结算对象候选仅含该类型下的对象；清空或切换对象类型时清空已选结算对象。

**结算对象**

- **候选范围**：当前页签下出现过的对象；仅自营后台视角。
- **展示**：展示为「账号（姓名）」。

**状态**

- **取值**：随页签取分账状态或账单状态。

**推广方手机号**

- **匹配**：模糊包含、忽略首尾空格；仅自营后台视角。

**月份**

- **匹配**：按月份匹配。

**重置**

- **行为**：清空本页签全部筛选项。
- **不影响**：不改变当前页签与视角。

- **占位符**：筛选项占位符直接用字段名，不加「全部」前缀。
- **生效方式**：筛选即时生效，不需点击查询按钮；所有筛选项不写入会话记忆，离开页面后重置。多个筛选项同时生效时取交集。
- **筛选项可见性**：推广方结算页签不展示周期、账期、对象类型、结算对象筛选项；其余页签不展示推广方手机号与月份筛选项。

【待确认】切换视角时除推广方手机号与已选结算对象外，是否需同步清空周期、账期与状态筛选。

## 列表字段

| 列 | 内容 |
| --- | --- |
| 账期 | 账期主文案 |
| 周期类型 | 周结 / 月结标签 |
| 结算对象 | 账号 + 名称两行 |
| 对象类型 | 景区商家 / 渠道 / 推广方标签 |
| 推广方名称 | 名称 |
| 手机号 | 手机号 |
| 应结算金额 | 金额 |
| 已分账净额 | 金额 |
| 分账状态 | 状态标签 |
| 账单状态 | 状态标签 |
| 发票 | 发票入口 |
| 操作 | 详情 |

**账期**

- **悬浮**：悬浮展示完整起止时间。
- 账期只有周结与月结两种，起止时间与订单归属判断统一以 UTC+8 为准。
- 周结为自然周，区间为周一 00:00:00 至下周一 00:00:00（左闭右开），名称展示为 `YYYY-MM-DD～YYYY-MM-DD`，结束日为周日。
- 月结为自然月，区间为当月 1 日 00:00:00 至次月 1 日 00:00:00（左闭右开），名称展示为 `YYYY年MM月`。
- 订单按支付时间归属账期，落在 `[账期开始, 账期结束)` 内的订单计入该账期；未支付成功（实付金额不大于 0）与已取消的订单不计入任何账期。
- 账期内无可结算订单时不生成账期行，不展示该账期。
- 账期主文案不展示「预估」标识。

**周期类型**

- **取值**：取自结算对象自身配置的结算周期；推广方固定使用月结。
- **展示**：周结蓝色、月结灰色。

**结算对象**

- **可见性**：仅自营后台视角。
- **悬浮**：悬浮展示「账号（姓名）」。

**对象类型**

- **可见性**：仅自营后台视角。

**推广方名称**

- **可见性**：仅推广方结算页签、仅自营后台视角。

**手机号**

- **可见性**：仅推广方结算页签、仅自营后台视角。

**应结算金额**

- **列名**：线上自动分账页签为「应分账金额」、推广方结算页签为「应分成金额」。
- **口径**：该账期内归属于该结算对象的订单结算金额合计。
- **辅助行**：仅景区商家账期在主行下方展示「基础 ￥X + 溢价 ￥Y」辅助行，两者之和等于主行金额；渠道、推广方账期不展示辅助行，溢价固定为 0。

【待确认·阻塞】渠道与推广方账期溢价固定为 0 后，历史含溢价数据的账期是否需按 0 回溯展示。

**已分账净额**

- **可见性**：仅线上自动分账页签。
- **口径**：max(0, 已分账金额合计 − 已回退金额合计)，按账期内订单汇总，不为负数。

**金额展示**

- 金额展示统一为 ￥ + 千分位两位小数。

【待确认·阻塞】已出账账期的金额是否随跨期退款、回退而变化，以及变化后的展示口径。

**分账状态**

- **可见性**：仅线上自动分账页签。

**账单状态**

- 账单状态与发票为现有系统能力，本 PRD 不定义。

**分页与空态**

- 每页 10 条，不提供每页条数切换，展示「共 N 条」；列表不提供排序。
- 账期无匹配数据时按页签展示空态：线下对公结算「暂无线下对公结算数据」、线上自动分账「暂无线上自动分账数据」、推广方结算「暂无推广方结算数据」。本人视角下无账期时同样展示对应空态。

【待确认】账期列表的默认排序规则（当前实现为不排序）。
【待确认】账期列表是否需支持导出。

## 列表操作

| 操作 | 位置 | 可用条件 |
| --- | --- | --- |
| 详情 | 行尾 | 所有行 |

**详情**

- **行为**：进入账期详情。

- **权限与入口**：线上自动分账页签不提供申请结算入口。

## 异常和边界

**页签**

- 切换到推广方结算页签时，同时清空周期、账期、对象类型、结算对象筛选；切换到其他页签时仅清空状态筛选。
- 会话记忆的页签值不属于三个页签时，回退默认页签。

- **视角**：切换视角时清空已选结算对象；切换为推广方视角时同时清空推广方手机号条件。
- **结算对象**：所选对象类型下无结算对象时，候选为空，可正常清空。
- **推广方手机号**：输入不存在的手机号时展示空表与对应空态文案。
