## 新增景区商家

### 一、分成配置

1. **结算周期**：必选。默认选中周结。
    - **周结**：按自然周（周一至周日）生成账期。
    - **月结**：按自然月（每月 1 日至月末）统计，次月 20 日出账单。
    - **修改生效**：已有结算周期时修改，不立即生效，在该字段下方提示「当前{原周期}，{新周期}将在当前账期结束后生效」。
    - **首次配置**：从未配置过结算周期时修改，立即生效。
    - **未选择**：提示「请选择结算周期」。

### 二、拍摄点分成

1. **拍摄点列表**：按「账号」自动带出该账号关联的运营拍摄点，逐行展示。
2. **分给自营平台比例/分给景区商家比例** ：收款主体为「景区商家收款」时显示「分给自营平台比例」，为「自营收款」时显示「分给景区商家比例」。
3. **溢价比例** ：只读。
    溢价比例 = 100% − （景区商家保留比例 + 收款商户自留比例 + 分给自营平台比例 / 分给景区商家比例 + 该拍摄点渠道 / 推广分成合计）

4. **单拍摄点合计校验**：同一拍摄点的景区商家分成、渠道分成与推广方分成合计不得超过 100%
    超出提示：「分成合计 {合计}%，超 100%（超 {超出}%），请调低收款商户自留或{分给自营平台比例 / 分给景区商家比例}比例」。
