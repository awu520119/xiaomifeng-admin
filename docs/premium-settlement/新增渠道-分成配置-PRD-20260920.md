# 新增渠道 · 分成配置 PRD

> 版本 v1.0　·　日期 2026-09-20

*需求场景：新增渠道成员时需要按拍摄点配置该渠道方应得的分成比例，并确保同一拍摄点上景区商家、渠道与推广方的分成合计不超过 100%。*

## 新增渠道

### 一、分成配置

1. **渠道类型**：必选。下拉单选，默认选中「渠道方」，选项包含「摄影师」「渠道方」「招商方」「投资方」「自定义合作方」。
2. **具体渠道类型**：仅「渠道类型」为「自定义合作方」时展示，必填。输入框，占位文案「请输入具体渠道类型」；未填写时提示「请输入具体渠道类型」。
3. **分账方式**：必选。默认选中「线下对公结算」，备选「线上自动分账」。
4. **结算周期**：必选。默认选中「月结」。
    - **周结**：按自然周（周一至周日）生成账期。
    - **月结**：按自然月（每月 1 日至月末）统计，次月 20 日出账单。
    - **修改生效**：已有结算周期时修改，不立即生效，在该字段下方提示「当前{原周期}，{新周期}将在当前账期结束后生效」。
    - **首次配置**：从未配置过结算周期时修改，立即生效。
    - **未选择**：提示「请选择结算周期」。
5. **分账接收方商户**：仅「分账方式」为「线上自动分账」时展示，必填。
    - **数据来源**：按输入的商户号查询商户信息与分账资格，查询来源待确认（见「待确认事项」1）。
    - **刷新时机**：输入商户号后自动发起查询并回显商户名称与分账资格；修改商户号后，已回显的商户名称与分账资格清空，需重新查询。
    - **取不到时**：商户名称未回显或分账资格未同步时，该字段提示「请输入并查询分账接收方商户」，且不可提交。

### 二、渠道分成规则（非必填）

1. **默认状态**：无规则，展示「暂无分成规则」；点击「新增规则」追加一行。
2. **行结构**：每行包含「拍摄点」「分成比例(%)」两项，行尾提供「删除」，删除后该行不再参与合计。
3. **列名联动**：「分成比例(%)」列名随「分账方式」变化：分账方式为「线下对公结算」时显示「分成比例(%)」，为「线上自动分账」时显示「分账比例(%)」。
4. **拍摄点**：必选。下拉单选，选项为全部运营拍摄点。
    - **唯一性**：同一拍摄点只能配置一条渠道规则；已被其他行选中的拍摄点，在当前行下拉中置灰不可选。
    - **未选择**：提示「请选择拍摄点」。
    - **行内重复**：与同一表单内其他规则行重复时，该行提示「同一拍摄点只能配置一条渠道规则」。
5. **分成比例**：必选。整数百分比，取值范围 0～100，单位 %；超出范围时提示「请输入 0-100% 的分成比例」。
6. **剩余可分提示**：每行下方展示该拍摄点的剩余可分比例。
    - **未超额**：该点分成合计未超 100% 时，提示「该点剩余可分 {剩余}%」。
    - **已超额**：该点分成合计超过 100% 时，提示「该点分成合计 {合计}%，已超 100%（超 {超出}%）」。

### 三、提交与校验

1. **提交拦截**：按下列顺序逐条校验，命中第一条即停止，由页面顶部提示该条错误，不继续校验后续项。

    | 序号 | 触发条件 | 提示文案 |
    | --- | --- | --- |
    | 1 | 未选择结算周期 | 「请选择结算周期」 |
    | 2 | 渠道类型为「自定义合作方」且未填写具体渠道类型 | 「请填写具体渠道类型」 |
    | 3 | 分账方式为「线上自动分账」且未填写分账接收方商户号 | 「线上自动分账需填写汇付商户号」 |
    | 4 | 分账方式为「线上自动分账」且商户名称未查询到、或分账资格未同步 | 「请查询汇付商户号并同步分账资格」 |
    | 5 | 存在不完整的规则行（未选择拍摄点，或分成比例不在 0～100） | 「请补充分成规则：拍摄点必选，分成比例需大于等于 0 且不超过 100%」 |
    | 6 | 同一拍摄点配置了多条规则 | 「同一拍摄点只能配置一条分成规则」 |
    | 7 | 跨成员合计超限 | 见「三、3」 |

2. **内联校验**：提交同时触发各字段的内联校验，字段提示文案见「一、分成配置」与「二、渠道分成规则」的对应条目。
3. **跨成员合计校验**：新增渠道成员的分成规则，与该拍摄点已配置的景区商家分成、推广方分成合计不得超过 100%。
    - **计入范围**：推广方分成只计入审核通过且未停用的推广方规则。
    - **超限处理**：超出时禁止提交，提示「「{景区名称}」渠道/推广分成合计 {合计}%，已超过剩余可分配 {剩余可分配}%。请调低渠道/推广分成比例。」
4. **提交成功**：校验全部通过后提交，提交成功后的页面行为与提示文案待确认（见「待确认事项」3）。

### 四、其他说明

- **银行账户**：「银行账户」字段组（开户名、银行名称、银行账号、开户行地址）标记为选填，本次不做规则调整。
- **角色限定**：本节仅在角色为「渠道」时展示；角色切换为其他角色后，已填写的分成配置按新角色重置。
