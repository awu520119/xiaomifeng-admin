## 一、结算管理-筛选项说明

1. **线上自动分账周期**：线上自动分账页签展示周期下拉，单选「周结」「月结」「T+1」。

2. **线上自动分账选择周期**：
    - **周结**：粒度到自然周，占位「选择周」，按所选日期所在自然周的周一与该账期起始日匹配。
    - **月结**：粒度到自然月，占位「选择月份」，按所选月份与该账期所属自然月匹配。
    - **T+1**：粒度到支付日，占位「选择支付日」，按所选支付日与账期起始日匹配。

3. **线下对公结算月份**：
    - 线下对公结算页签仅展示月份选择器「选择月份」，按自然月账期筛选。

4. **推广方结算月份**：
    - 推广方结算页签仅展示月份选择器「选择月份」，按自然月账期筛选。

## 二、结算管理-列表说明

1. **结算账期**：
    - **月结**：展示「YYYY年MM月」。取自然月（当月 1 日 00:00 至次月 1 日 00:00，左闭右开）
    - **周结**：展示「YYYY-MM-DD～YYYY-MM-DD」；取自然周（周一 00:00 至下周一 00:00，左闭右开）
    - **T+1**：展示订单支付日「YYYY-MM-DD」。同一结算对象、同一支付日的可分账订单合并为一笔账期，次日自动分账。
    - **跨月周结**：完整展示自然周范围，不在月末拆分。

2. **周期类型**：
    - **景区商家/渠道**：按配置带出周期类型「周结」「月结」或「T+1」。
    - **推广方账期**：固定展示「月结」。

3. **溢价**：
    - 只有收款主体为「景区商家收款」的景区商家账期才有溢价。
    - **金额构成**：存在溢价的账期，应结算金额 = 基础分成 + 溢价。
    - **无溢价不展示**：收款主体为「自营收款」的景区商家账期，以及渠道账期、推广方账期，不展示溢价。

4. **分账异常标识**：
    - 仅线上自动分账页签。账期内存在异常订单时，在「应分账金额」右侧展示红色异常图标。
    - **异常判定**：账期内存在分账状态为「分账失败」，或回退状态为「回退失败」的订单。
    - **悬浮提示**：展示「分账异常：分账失败 {x} 笔 / 回退失败 {y} 笔，请查看明细」；某一类为 0 笔时只展示另一类。
