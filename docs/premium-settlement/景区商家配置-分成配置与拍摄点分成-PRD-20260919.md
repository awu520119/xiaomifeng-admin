# 景区商家配置-分成配置与拍摄点分成 PRD

> 版本：v1.0　·　日期：2026-09-19

## 1. 需求背景

**背景**：支持景区商家配置结算周期和拍摄点分成，并在配置时查询商户名称、分账资格及拍摄点剩余可分配空间。

## 2. 用户操作主流程

**主流程**：手动输入商户号并查询商户信息 → 选择结算周期 → 配置拍摄点分成比例 → 查看自动计算的溢价比例 → 保存。


## 结算周期

**结算周期规则**

| 结算方式 | 周结 | 月结 |
| --- | --- | --- |
| 线上自动分账 | 自然周结束后的次周一 10:00 发起分账 | 自然月结束后的次月 1 日 10:00 发起分账 |
| 线下对公结算 | 自然周结束后生成账单，进入线下结算流程 | 次月 20 日生成上月账单，进入线下结算流程 |

| 收款主体 | 资金流向 | 使用的规则 |
| --- | --- | --- |
| 自营收款 | 自营平台 → 景区商家 | 使用本字段的周结或月结 |
| 景区商家收款 | 景区商家 → 自营平台 | 不使用本字段；平台入账选实时或 T+1。实时为支付成功且通道允许后立即发起，T+1 为支付次日 10:00 发起 |
| 景区商家收款 | 景区商家 → 渠道 | 使用渠道自己的结算周期 |

**统一规则**

- 同一拍摄点中，景区商家和渠道可分别选择周结、月结；各自独立归集、独立发起，不要求周期一致。
- 全部时间以 UTC+8 为准。订单按支付成功时间归属；取消订单、实付金额不大于 0 的订单不参与结算。
- 每个对象在每个周期只生成一笔分账批次或一张线下账单；分账失败在原批次重试，不滚入下期。

**配置生效**

- 首次配置直接生效。
- 已生效后修改时，新周期在当前账期结束后生效；当前账期仍按原周期执行，已生成账期不重新计算。
- 待生效时提示“当前{原周期}，{新周期}将在当前账期结束后生效”；改回当前周期时取消待生效。
- 未选择结算周期时，保存提示“请选择结算周期”。

### 商户号查询（优化）

**适用字段**：收款商户号、分账接收方商户。

- 支持手动输入商户号后按回车或点击查询按钮。
- 查询成功后回显商户名称与分账资格。
- 修改商户号后立即清空原查询结果；重新查询成功前不展示名称与资格。

### 拍摄点分成

展示说明：“各方分成比例合计 ≤ 100%，剩余比例自动计为收款商户溢价。”

**拍摄点**
- 数据来源：取拍摄点配置所选账号关联的运营拍摄点

**收款商户自留比例与分给比例**

- 收款主体是「自营收款」，则拍摄点分成列名是「分给景区商家」比例
- 收款主体是「景区商家收款」，则拍摄点分成列名是「分给自营平台」比例

**溢价比例与容量**

| 项目 | 规则 |
| --- | --- |
| 展示 | 溢价比例只读，取值范围为 0～100 |
| 计算 | 溢价比例 = 100% − 收款商户自留比例 − 分给比例 − 该点渠道已配置合计 − 该点推广已配置合计 |
