# 渠道配置-分成配置 PRD

*让渠道的每条分成规则在填写时就能看到该拍摄点的剩余可分配空间，避免各方合计超过 100% 导致该点订单无法分成。*


**结算周期**

- 必填、单选
- **线上自动分账**：结算周期只控制分账的发起时间。周结按自然周归集，在次周一 0:00 发起；月结按自然月归集，在次月 1 日 00:00 发起。
- **线下对公结算**：结算周期只控制账单的归集和出账。周结在自然周结束后出账；月结在次月 20 日生成上月账单，均进入线下结算流程。

- **辅助说明**：选项后有说明图标，周期说明收在图标内，页面不常驻说明文字。
- **生效方式**：首次配置直接生效；已生效后再改，记为待生效周期、当前账期结束后生效，字段下方提示「当前{原周期}，{新周期}将在当前账期结束后生效」；改回当前周期则取消待生效。

**分账接收方商户**

- 支持输入框回车或点查询按钮发起；查询完成后按商户号回显商户名称与分账资格。
- 未查询、未匹配到商户、资格未同步三者任一即禁止保存，保存提示「请输入并查询分账接收方商户」。

## 渠道分成规则

**拍摄点**

- 仅可选择已归属景区商家账号的拍摄点，其他拍摄点置灰不可选。
- 已在其他分成规则行选择的拍摄点不可再选。

**分成比例(%)**

- 不得超过该拍摄点的剩余可分比例。
- 剩余可分比例 = 100% − 景区商家侧小计 − 该点渠道已配置合计 − 其他推广方在该点已配置合计。
- 超出时保存提示“该点可分配 {剩余}%，超出{超出}%”。
