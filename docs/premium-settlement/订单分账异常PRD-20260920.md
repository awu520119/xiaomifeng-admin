## 订单详情（分账失败 / 回退失败）

1. **分账状态**：
    - **分账失败**：全部分账流水失败时展示「分账失败」。

2. **回退状态**:
    - **回退失败**：状态展示「回退失败」，展示「原因：{失败原因}」。
    
3. **重试入口**：
    - **权限**：仅当前账号拥有该功能的编辑权限时展示；无编辑权限时不展示「重试分账」与「重试回退」，失败原因仍正常展示。
    - **多笔失败**：展示「重试失败分账」，一次重试全部失败流水；已成功流水不重复发起。
    - **二次确认**：两种失败类型均为一句说明，不展示订单号、分账或回退金额、收款方与失败原因。
        - **分账失败**：标题「确认重试分账？」，说明文案「重试后将重新发起失败分账。」
        - **回退失败**：标题「确认重试回退？」，说明文案「重试后将重新发起该笔回退。」
    - **重试**：部分失败则只重试部分失败的内容。
