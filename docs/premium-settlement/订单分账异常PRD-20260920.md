## 订单详情（分账失败 / 回退失败）

1. **分账状态**：
    - **分账失败**：订单存在一笔或多笔分账流水失败时展示「分账失败」。

2. **多笔分账流水与失败原因**：
    - **分账流水号**：订单存在多笔分账流水时，直接展示全部流水号，并以中文逗号「，」分隔；
    - **失败原因**：
        - 「原因：{失败流水号}：{失败原因}」。
        - 存在多笔失败流水时，各组「失败流水号：失败原因」以中文逗号「，」分隔。

3. **回退状态**:
    - **回退失败**：状态展示「回退失败」，展示「原因：{失败原因}」。
    
4. **重试入口**：
    - **权限**：仅当前账号勾选订单的「退款」权限时展示；无编辑权限时不展示「重试分账」与「重试回退」，失败原因仍正常展示。
    - **二次确认**：两种失败类型均为一句说明，不展示订单号、分账或回退金额、收款方与失败原因。
        - **分账失败**：标题「确认重试分账？」，说明文案「重试后将重新发起失败分账。」
        - **回退失败**：标题「确认重试回退？」，说明文案「重试后将重新发起该笔回退。」
    - **重试**：部分失败，只重试失败部分。
