# 结算中心-账期详情 PRD

*让结算对象与运营在账期详情中下钻到订单级明细，核对每一笔订单的分成与分账结果。*

## 页头与摘要

**汇总指标**

- **景区商家账期**：根据景区商家配置的收款主体决定金额拆分方式。
  - 收款主体为「景区商家」时，展示「基础分成金额」和「溢价」两个指标，二者之和等于范围内订单归属于该景区商家的应结算金额合计。
  - 收款主体为「自营」时，景区商家实际不产生溢价，不展示「溢价」指标，仅展示基础分成金额和应结算金额。
- **渠道与推广方账期**：不展示基础分成金额和溢价拆分，仅展示对应对象的应结算金额；渠道与推广方账期不单列溢价。


**结算规则**

- **通用文案**：「按比例  N%」。
- **景区商家账期**：
  - 收款主体为「景区商家」时，结算规则下方增加「基础分成 ￥X + 溢价 ￥Y」辅助行。
  - 收款主体为「自营」时，景区商家不产生溢价，不展示「溢价」辅助项，仅展示基础分成金额；不得展示「溢价 ￥0」或其他溢价占位文案。
- **渠道与推广方账期**：仅展示「按比例  N%」，不区分基础分成或溢价辅助行。
